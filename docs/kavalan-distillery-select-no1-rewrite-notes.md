2026-09-14作成。同日、本人よりカフェグレーンと合わせて公開・プッシュの承認。記事日付は本人指定の9月13日。

## 本人の感想と未確定事項

- 本人の共有内容：バナナやトロピカルな香り。ノンエイジで、同価格帯には長期熟成の良いウイスキーも多いためコスパを低めに評価したい。
- 初稿では星を保留。2026-09-14の追加指示で参考レビューに基づく採点を委任されたため、ストレート4／ロック3／ハイボール4（本人指定）／コスパ2.5（本人指定の3以下）／総合3.5（仮案）を設定。ストレートは複数の好評と軽めの味わいを考慮し4、ロックは好評もある一方で酸味・渋みへの否定的な感想が複数あるため3。単純な平均点ではなく本文に合わせた編集上の評価案。おすすめは同点のストレートとハイボール。Labのmineは変更していない。
- 香り以外の香味・飲み方はラボ共通傾向からの原稿案であり、本人の実飲として確認が必要。未共有の購入場所、価格、体験は作らない。
- 写真は本人提供のIMG_3113.jpgを使用。2026-09-14に仮のOGP画像から差し替え。元写真の構図を維持し、配信用の縮小はAstroで行う。
- 本人の公開承認によりdraft:falseで公開する。蒸留所写真IMG_1143.jpgと指定のfigcaption、中央寄せ・グレー・13pxのキャプションスタイルを追加済み。楽天700ml単品の画像とリンクも取得済み。
- 価格欄は未設定。2021〜2025年の口コミ価格を現在価格として流用しない。

## 確認資料

- `../whisky-lab/data/kavalan-distillery-select-no1.json`を全件確認。単体実飲4件（ぴろ、ひろりんパパ、なもなきアクアリウム、いのかず）。記事なし4件とブランド解説1件は共通評価に数えない。
- [なもなきアクアリウム](https://asgsn.hatenablog.com/entry/2025/02/23/190000)：原ページ確認。バナナ、バニラ、キャラメル、スパイス。ロックは渋み、ハイボールは好意的。
- [いのかず](https://inokazu.com/kavalan-distillery-select-no1/)：原ページ確認。果実感と軽めのボディ。ロックにも好意的で、酸味・渋みへの否定は全員一致ではない。
- ひろりんパパ：ラボ要約で確認。ロックは人工的な酸味に強く否定的。固有の比喩や極端な採点を自分の評価へ移植しない。
- ぴろ：ラボ要約で確認。人工的な果実感に否定的。本人は香りを好意的に捉えているため、主たる香味に採用しない。
- [Kavalan発表・2020-05-04](https://www.prnewswire.com/news-releases/kavalan-creates-entry-level-range-to-capture-broad-market-301051604.html)：700ml、40%、入門シリーズ、リフィル樽、No.1はトロピカル・No.2は花とハーブ、2020年No.1のラベル変更時はレシピ不変。メーカー発信の一次資料。具体的な樽内訳はここでは示されていないので「リフィル樽」に留めた。
- [三越伊勢丹の商品ページ](https://www.mistore.jp/shopping/product/900000000000000002627660.html)：現行掲載確認。終売・後継品への変更は確認できず、記事にそのような断定はしない。
- 熟成年数4年、スコッチの12年相当、熟成速度3〜4倍などは一次資料で確認できていないため不採用。ノンエイジを短熟の証明や低品質の根拠にしない。
