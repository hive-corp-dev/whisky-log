# ジョニーウォーカー15年 シェリーフィニッシュ改稿メモ

2026-09-11。本人より完成了承。最後に発売地域の補足を「今もこの3市場だけの限定品というわけではなさそうです。」へ変更。以下の確認待ち記録は改稿時点の履歴として残す。対象は15年のブレンデッドモルト。12年ブラックラベルのシェリーフィニッシュとは別商品。

## 今回の変更と確認待ち

- 追加指示：Cardhuは[日本酒類販売の発売案内](https://www.nishuhan.co.jp/news/2018/20180727.html)で「カーデュ」を確認し、記事の基本情報と本文を修正。「とは」のポイント直後にH3「中国・台湾・マレーシア向けに発売」を追加。
- 発売地域は[Luxurious Magazine（2020-11-18）](https://www.luxuriousmagazine.com/johnnie-walker-15-years-sherry-whisky/)の3市場限定との記述、[Malaysian Foodie（2020-10-09）](https://www.malaysianfoodie.com/2020/10/johnnie-walker-aged-15-years-sherry-finish.html)の中国・台湾に続くマレーシアでの紹介を確認。中華料理とのペアリングという発売背景も短く記載。同時発売や2020年の世界初発売とは書かない。現在の豪州公式掲載とは時点を分ける。

- 本人から共有された「台湾で日本円約5,000円で購入」を導入へ反映。購入年月・店名・購入動機は創作せず、現在相場や日本の参考価格にも転用しない。
- Labの全ソースとmineを確認。mineは未入力。既存の星（ストレート4／ロック4.5／ハイボール3.5／コスパ3.5／総合4）は維持し、本人の新たな確定評価とは扱わない。
- 本文は参考資料に基づく改稿案。本人の実飲感想としての最終確認は必要。特にハイボールは追加調査でも具体的な実飲記述が見つからず、元稿の「軽い甘さ・すっきり・ロックより控えめ」を簡潔に残した。新たな香味や混合比率、食事相性は足していない。ここを複数ソースの共通評価とは呼ばない。
- ロックは台湾の実飲記事で蜂蜜の甘さ、花の香り、軽やかさを確認。おすすめは据え置き。旧稿の「冷やすとレーズンとカカオが前に出る」「氷が溶けても崩れない」は根拠がなく削除。
- 香味は蜂蜜・果実・ナッツ・なめらかさを中心に整理。スモークの有無、余韻の長さは資料間で相違があり断定しない。煙を必須の特徴として扱わない。
- 「誰が飲んでもおいしい」「グリーンラベルをシェリー樽で仕上げたもの」という印象、未確認の海外価格序列を削除。
- URL・アイキャッチ・購入ボックス非表示を維持。国内発売なしは本人情報に沿うが、「今もアジア限定」とは書かない（豪州公式ページと現地購入レビューあり）。
- 旧稿とLabの「2020年代発売」は2019年の台湾記事と矛盾するため採用しない。Lab原データは変更していない。

## 今回確認した原ページ

### 公式情報

- [Johnnie Walker豪州公式](https://www.johnniewalker.com/en-au/our-whisky/core-range/johnnie-walker-aged-15-years-sherry-cask-finish)：15年ブレンデッドモルト、40％、700ml、カードゥ・クライヌリッシュ・グレンエルギン等、15年以上の熟成後ヘレス産シェリー樽で追加熟成。検索取得の製法段落と原ページの商品表記を確認。本文では製法段落にリンク。現行の商品ページあり。終売・後継品を示す情報は確認できず、終売とは書かない。

### 実飲記事・発売紹介

- [My Whisk'e'y Diaries / Donnie](https://mywhiskeydiaries.com/2024/11/26/review-johnnie-walker-15-yo-sherry-finish-blended-whisky/)（2024-11-26、独立した個人の実飲記事）：甘さ、ドライフルーツ、ナッツ、ドライさ・渋み、穏やかなスパイス。飲みやすいがやや薄い、グリーンラベルほどの洗練さがないという評。「気になる声」2項目はこの一人の意見を要約したもので多数意見ではない。100豪ドルという当時の価格は日本の相場に転用しない。
- [一飲樂酒誌 / Ma Matt](https://www.1shot.tw/15849/新品開箱-johnnie-walker-15年封蜜雪莉桶威士忌-全新赫雷斯雪)（2019-09-24、末尾にAD表記）：ストレートと大きな氷での実飲比較。蜂蜜とナッツ、軽い口当たり、加氷時の甘さと花の香りを確認。ロックを勧めている。広告記事であることを記録し、独立した口コミ多数とは扱わない。日本語は独自の短い要約で、原文の比喩や構成を移植しない。
- [鏡週刊 / 夏日品飲筆記特輯](https://www.mirrormedia.mg/story/20200717mkt001)（2020年、企画記事）：蜂蜜、ナッツ、焼いたリンゴ、果実菓子、チョコレート、なめらかさ。ストレートとロックに好意的。広告的な企画である点を考慮し、一般消費者レビューには数えない。食事相性や筆者の経験は本人の体験として転用しない。
- [Loy's Bar](https://loystory.com/20)（2024-08-30）：韓国での購入記録。香味欄は「公式テイスティング情報」と明記されているため、独立した実飲評価に数えない。

英語・繁体字・韓国語でハイボール関連語も検索。販売店の商品紹介に提案はあるが、具体的な飲み比べ根拠にはしなかった。12年ブラックラベルやグリーンラベルの検索結果は除外。
