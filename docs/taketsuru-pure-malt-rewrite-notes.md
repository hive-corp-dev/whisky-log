# 竹鶴ピュアモルト 記事メモ（2026-10-05 初稿）

## 本人からの情報

指定なし。体験は足していない。

## 点数（Claude が決定、ラボ参考）

ストレート4 / ロック4.5 / ハイボール4.5 / コスパ4（本人指定。理由: 余市・宮城峡と同じ希望小売価格で、ブレンデッドモルトとして考えれば良いほう） / 総合4.5（総合は本人指定、2026-10-05。ロックとハイボールはそれに合わせて Claude が引き上げ）、おすすめは rock + highball。初稿は 4 / 4 / 4 / 3 / 4。
根拠: ひろりんパパ（ストレート3 / ロック4 / ハイボール3.5 / 総合3、価格への不満）、なもなきアクアリウム（ロック推し、どう飲んでも美味しい）、ゆうの家飲み（ストレートとハイボール推し）、ウイスキートマト（どの飲み方でも破綻しない）、宅飲み（ハイボールが食中酒として抜群）。

## 香味の言葉

りんご（全員、公式ノートにも）、バニラ・カスタード、バナナ（ゆう、ひろりん、公式）、モルトのコク、穏やかなスモーク（全員。ゆうは「かなりスモーキー」）、余韻のビターチョコ（公式）、若い原酒のピリピリ感（ゆう）。柑橘（ひろりん、なもなき、公式のネーブルオレンジ）は、アードベッグのレモンの件を踏まえて入れていない。
