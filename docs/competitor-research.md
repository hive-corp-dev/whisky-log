# 競合調査と構成案（2026-09-05）

Whisky Log の記事執筆に入る前に、日本語のウイスキー紹介ブログ 15 サイトを調べ、
サイト構成・記事構成・収益導線・狙っているキーワードを読み取った結果と、それを踏まえた Whisky Log の構成案。

---

## 1. 結論（先に要点）

**Whisky Log が取るべきポジション**

> 「実際に飲んだウイスキーを、自分の写真つきで、ストレート／ロック／ハイボール別に評価して淡々と記録する」
>
> ※ 2026-09-05 追記: 当初は「安価帯・初心者」を軸にしていたが、書き手を「初心者」と名乗らない・価格帯で縛らない（高いボトルも扱う）方針に変更。差別化は「実飲写真・飲み方別・一貫した評価」で作る。

この組み合わせを完全に実装しているサイトは 15 サイト中ひとつもなかった。近いサイトはそれぞれ穴がある。

| 近い競合 | 穴 |
|---|---|
| ゆうの家飲みウイスキーブログ | 飲み方別レビューの型は最も近いが、収益化ゼロで 2023 年に更新停止 |
| いのかず（Whisktender） | 収益導線は最強だが「バーテンダー目線」で、角瓶・トリス・バスカー等の最安価帯が未掲載 |
| ぴろのウイスキーブログ | 悩み系タイトルは巧いが、飲み方別の記述がなく Amazon 一択 |
| スニフ（whisky-daigaku） | 最も近い競合。ただし焼酎・缶チューハイに拡散中で、自撮り写真が少ない |
| 酒おやじ | SEO 設計は最も参考になるが 1 記事 15,000 字で重く、写真がイメージ写真 |
| ウイスキーを知る | 「○○はまずい？」型を量産しているが匿名・実飲写真なし・更新停止気味 |

**やること（優先順）**

1. レビュー記事のテンプレートを「結論先出し → 基本情報表 → 香り/味/余韻 → 飲み方別 → まずい？の真相 → 総評（★） → こんな人に → FAQ」に固定し、3,000〜5,000 字に収める
2. 収益導線は Amazon / 楽天 / Yahoo の 3 ボタン（もしもアフィリエイト「かんたんリンク」相当）を「基本情報表の直後」と「総評の直後」の 2 箇所に固定
3. タイトルは「{銘柄}はまずい？」「{銘柄} レビュー・評価｜{味の一言}」の 2 型を使い分ける
4. ビッグワード（「ウイスキー おすすめ」「安い ウイスキー ランキング」「ハイボール おすすめ」）は mybest / SAKELOG が独占しているので**最初は狙わない**
5. 代わりに「{銘柄} まずい」「{銘柄A} {銘柄B} 違い」「{ブランド} 全種類 違い」「{銘柄} 開栓後 変化」など、競合が空いている指名系・比較系を先に埋める
6. サイト側には「プロフィール」「プライバシーポリシー」「お問い合わせ」ページが必須（Amazon アソシエイト審査条件でもある）

## 3. 読み取れた共通パターン

### 3-1. レビュー記事の見出し構成

成果を出しているサイト（いのかず・酒おやじ・sister-ley・ウイスキーを知る）に共通する骨格。

```
リード（結論を先に 2〜3 行で）
├─ H2 {銘柄}の基本情報          ← スペック表 + 3 ボタン
├─ H2 {銘柄}を飲んでみたレビュー
│   ├─ H3 香り
│   ├─ H3 味わい
│   ├─ H3 余韻
├─ H2 飲み方別の評価
│   ├─ H3 ストレート             ← グラス写真 + おすすめ度
│   ├─ H3 ロック
│   ├─ H3 ハイボール             ← 比率（1:3 など）を数字で書く
├─ H2 「{銘柄}はまずい」の真相    ← ネガ検索意図を受け止める
├─ H2 総合評価                   ← ★ + 3 ボタン
├─ H2 こんな人におすすめ / おすすめしない
├─ H2 同ブランドの他ボトル・似ている銘柄   ← 内部リンク
├─ H2 よくある質問
└─ H2 まとめ
```

**文字数**は 3,000〜5,000 字がボリュームゾーン。酒おやじ・sister-ley は 8,000〜15,000 字だが「初心者には重い」のが弱点。

**基本情報表の項目**（各サイトの和集合から必要なものを選定）

| 項目 | 採用サイト |
|---|---|
| 商品名 / メーカー / 蒸留所 | ほぼ全サイト |
| 産地 / 分類（ブレンデッド等） | ほぼ全サイト |
| 度数 / 容量 | ほぼ全サイト |
| 参考価格（取得年月つき） | sister-ley, 酒おやじ, ひろりんパパ |
| **1 杯（30ml）あたりの価格** | ひろりんパパ, 酒おやじ, mybest（ml 単価） |
| おすすめの飲み方 | sister-ley |
| 熟成樽 | Whisky Roundup |

### 3-2. 評価方式

| 方式 | サイト | 向き不向き |
|---|---|---|
| ★5 段階 × 複数軸（香り/味/コスパ/飲みやすさ） | 酒おやじ | 一目で分かる。初心者ブログに最適 |
| 飲み方別 25 点 × 4（ストレート/ロック/ハイボール/価格） | talisker-mania | Whisky Log の 3 飲み方方針に直結 |
| 100 点 + レーダーチャート | Whisky Roundup | 玄人向け、辛口が出しにくい |
| S+〜C グレード | ぴろ | 一貫性はあるが軸が見えない |
| なし | ゆう, sister-ley, スニフ, ウイスキーを知る | 弱点として挙げられる |

### 3-3. 収益導線

- **3 ボタン（Amazon / 楽天 / Yahoo）が個人ブログの標準**。実装は「もしもアフィリエイト かんたんリンク」「Rinker」「Pochipp」のいずれか
- 設置位置の定石は **基本情報表の直後** と **総評の直後** の 2 箇所。まとめ記事は各銘柄 H3 の直後
- 酒おやじは炭酸水・製氷器・おつまみなど**周辺グッズも収益化**（1 記事 9 箇所）
- Amazon 単独（ぴろ・ひろりんパパ）は楽天派を取りこぼすと複数のサイトで弱点として観察された
- 料率: Amazon「お酒」カテゴリは 8%（公式紹介料率表）、楽天は 4% 前後。Amazon の Cookie は 24 時間、楽天・Yahoo は 90 日
- Amazon アソシエイト審査: 10 記事以上、プライバシーポリシー、お問い合わせ、180 日以内に 3 件の売上。**もしも経由なら 3 件ノルマなし**で通りやすい

### 3-4. タイトルの型

| 型 | 例 | 使っているサイト |
|---|---|---|
| ネガ疑問 | 「{銘柄}はまずい？美味しい？味・香り・おすすめの飲み方を徹底解説」 | ウイスキーを知る, ぴろ, 酒おやじ |
| レビュー宣言 + 味の一言 | 「レビュー｜{銘柄}【甘くビターでスコッチっぽい】」 | いのかず, sister-ley |
| 正直レビュー | 「{銘柄}の評価｜○○の実力を正直レビュー」 | 酒おやじ |
| 権威づけ | 「245本飲んだ筆者が」「バーテンダー厳選」「プロが解説」 | ぴろ, いのかず, スニフ |
| 事実系 | 「{銘柄}は終売？売ってない理由と買い方」「{ブランド}全種類と違い」 | ぴろ, SAKELOG, Whisky Trend |

Whisky Log は権威づけが使えないので、**ネガ疑問型 + 味の一言型**を基本に、「初心者が」「家で」を差別化ワードにする。

### 3-5. まとめ・ランキング記事

- **価格帯別**（1,000 円台 / 2,000 円台 / 3,000 円台）が最も多い型。各帯 5〜6 本
- 冒頭に**比較表**（銘柄 / 産地 / 度数 / 価格 / おすすめの飲み方）を置く
- 1 本あたり 200〜300 字 + スペック + 3 ボタン + **個別レビューへの内部リンク**
- 選定基準を明示する（ゆう: 2,000〜3,000 円・ハイボールで美味い・スーパーで買える）
- ひろりんパパの「10 本飲み比べて 1 本に絞る」型はユニークで真似しやすい

### 3-6. 内部リンク

- **同ブランドの他ボトル**ブロック（ブラックニッカ クリア / スペシャル / ディープ / リッチ）は複数サイトで定型化
- まとめ ⇄ 個別レビューの双方向リンク（いのかず・sister-ley・酒おやじ）が回遊の要
- タグで「ハイボールに合う」「安くて美味しい」「初心者向け」の横断導線（sister-ley・いのかず）

## 4. キーワード戦略

大手（mybest / SAKELOG）が固めているビッグワードを避け、指名系・比較系から入る。

### 4-1. 最初に狙う型（競合が空いている）

| 型 | 例 | 根拠 |
|---|---|---|
| {銘柄} まずい | 陸 まずい / トリス まずい / ブラックニッカ スペシャル まずい | Whisky Trend が一般論のみ。実飲 + 率直な評価で取りやすい |
| {銘柄A} {銘柄B} 違い / 比較 | 陸 vs 知多 / トリス vs 角瓶 / バスカー vs ジェムソン | 大手はロングリストで 2 本比較をしない |
| {ブランド} 全種類 違い | ブラックニッカ 種類 違い / バスカー 青 緑 違い | SAKELOG がバスカーのみで 2024 年停止 |
| {銘柄} ハイボール | ブラックブッシュ ハイボール | 濃度・炭酸の実験写真で差別化 |
| {銘柄} 開栓後 変化 | ウイスキー 開けてから 何日 | 誰も扱っていない |
| {銘柄} 缶ハイボール vs 自作 | 角ハイボール缶 自作 比較 | スニフが缶レビューのみ |
| {店} で買える | コンビニ / 業務スーパー / ドンキ / コストコ ウイスキー | 生活文脈で大手が弱い |

### 4-2. 後で狙う型（中程度）

- {銘柄} 飲み方（Whisky Trend が AI 量産しているが中身が空）
- {銘柄} 定価 / 値段（低〜中価格帯は空き気味）
- {銘柄} 終売 / 代わり
- {銘柄} 何年 / ノンエイジ 違い
- {季節・用途} 3,000 円以下 ウイスキー（父の日 / 一人飲み）

### 4-3. 最初は避ける型

- ウイスキー おすすめ / 初心者 おすすめ（mybest 227 商品）
- 安い ウイスキー ランキング（mybest, 酒おやじ, sister-ley）
- ハイボール ウイスキー おすすめ（SAKELOG 37 選, mybest）

## 5. Whisky Log の構成案

### 5-1. サイト構成（ページ種別）

```
/                          トップ（新着レビュー + 価格帯別まとめへの導線）
/review/                   レビュー一覧
/review/[category]/        産地別一覧（現状維持）
/review/[category]/[slug]  レビュー記事
/compare/[slug]            飲み比べ・比較記事（{A} vs {B}、全種類の違い）  ← 新設
/guide/[slug]              まとめ・入門（価格帯別、飲み方別、店別）        ← 新設
/tag/[tag]                 タグ横断（ハイボール向き、1,000円台、初心者向け） ← 新設
/profile                   プロフィール（誰が・なぜ・どう評価するか）      ← 必須
/privacy-policy            プライバシーポリシー + アフィリエイト表記        ← 必須
/contact                   お問い合わせ（Google フォーム埋め込みで可）     ← 必須
```

現状の `review` コレクションに加え、`compare` と `guide` のコレクションを増やす。
タグは現在の分類（ブレンデッド等）に加えて、**用途タグ**（`highball` / `beginner` / `under-2000` / `under-3000` / `convenience-store`）を持たせる。

### 5-2. レビュー記事の frontmatter 追加項目

```yaml
# 既存
draft, title, description, image, category, tags, country, publishedAt, updatedAt

# 追加
maker: "ニッカウヰスキー"
distillery: "宮城峡・余市"          # 任意
abv: 42
volume: 720
price: 1500                        # 参考価格（円）
priceCheckedAt: "2026-09"          # 価格取得年月
rating:                            # ★1〜5
  straight: 3
  rock: 3
  highball: 4
  cost: 5
  overall: 4
recommendedWay: "highball"         # straight | rock | highball
amazon: "https://..."              # アフィリエイト URL（もしも経由）
rakuten: "https://..."
yahoo: "https://..."
relatedBottles: ["black-nikka-clear", "black-nikka-deep-blend"]   # 同ブランド
```

`price` と `volume` から「1 杯（30ml）あたり ○円」を自動計算して基本情報表に出す。

### 5-3. 記事内で使うコンポーネント（新設）

| コンポーネント | 役割 | 参考サイト |
|---|---|---|
| `<Verdict>` | 冒頭の「3 行で結論」ボックス | ぴろ「3秒でわかる」, ゆう「3行で！」, 酒おやじ |
| `<SpecTable>` | frontmatter から基本情報表を自動生成（1 杯単価つき） | ひろりんパパ, 酒おやじ |
| `<AffiliateButtons>` | Amazon / 楽天 / Yahoo の 3 ボタン。frontmatter の URL を使う | いのかず, 酒おやじ, スニフ |
| `<Rating>` | ★5 × 4 軸 + 総合。飲み方別に「おすすめ度」 | 酒おやじ, talisker-mania |
| `<TastingNote>` | 飲み方ごとの「写真 + 香り / 味 / 余韻 + おすすめ度」を定型で | ゆう, ウイスキーを知る |
| `<Recipe>` | ハイボールの比率・炭酸・氷を数字で | 酒おやじ |
| `<ProsCons>` | こんな人におすすめ / おすすめしない | sister-ley, 酒おやじ |
| `<RelatedBottles>` | 同ブランド他ボトル・似ている銘柄（frontmatter から自動） | ゆう, sister-ley, asgsn |
| `<FAQ>` | よくある質問（構造化データ `FAQPage` も出力） | 酒おやじ, ぴろ |
| `<CompareTable>` | まとめ・比較記事用の比較表 | sister-ley, SAKELOG, 酒おやじ |

既存の `<Speech>`（吹き出し）は「初心者のひとこと感想」用に残す。

### 5-5. 写真の撮り方（ユーザー側の作業）

競合で「実飲写真が少ない・イメージ写真」が弱点として繰り返し出ているので、写真が最大の差別化になる。

- ボトル正面（thumb.jpg、16:9 でトリミングできる余白を残す）
- ラベル寄り（度数・容量が読める）
- ストレート / ロック / ハイボールのグラス写真を**同じ場所・同じ背景**で（統一感がブランドになる）
- 可能なら「一緒に飲み比べた 2 本を並べた写真」（比較記事用）

## 6. 収益設定の手順

### 6-1. 直接契約か、もしも経由か

競合の多くが「もしもアフィリエイト」を使っている理由は、(1) 3 社を 1 つの管理画面で扱える、(2) 3 ボタンを自動生成する「かんたんリンク」がある、(3) Amazon の審査が直接より緩い、(4) 1,000 円から現金振込、の 4 点。
ただし Whisky Log は 3 ボタンを自前コンポーネントで作るので (2) は関係なく、**プログラムごとに有利な方を選ぶハイブリッドが合理的**。

| | 直接契約 | もしも経由 | 判断 |
|---|---|---|---|
| Amazon | お酒 8.00%。紹介料増額キャンペーン対象。180 日以内に 3 件の売上がないと本審査落ち。振込は 5,000 円から（ギフト券は 500 円から） | お酒 **7.20%**（直接の 90%）。キャンペーン対象外。スマホアプリで開くと成果にならない場合あり。審査が緩い。1,000 円から振込 | **直接**。10 記事そろえて公開時に申請。落ちたらもしもに切替 |
| 楽天 | 報酬は原則**楽天キャッシュ**。現金振込は「3 ヶ月連続で月 3,001 円以上」+ 審査 + 半年ごとの再審査が必要。ウイスキーの料率は 4% | 1,000 円から**現金**振込 | **直接**（数年前に登録済みの有効なアカウントがあるため）。whisky-log.com を「サイト情報の登録」に追加し、記事ごとに管理画面で生成した URL を `links.rakuten` に貼る。現金化が必要になったら銀行振込を申請 |
| Yahoo! | 直接プログラムはなく、バリューコマース経由（約 1.0%）か、もしも経由（0.77%）。2026 年 1 月からジャンル別料率に改定 | 同左 | ウイスキーでの Yahoo 経由売上は小さいので、当面は**もしも**で一本化。伸びたらバリューコマースに切替 |

### 6-2. 手順

1. **もしもアフィリエイト**に登録し、楽天・Yahoo と提携（Amazon はここでは提携しない）
2. 公開時（10 記事以上、プロフィール・プライバシーポリシー・お問い合わせ設置後）に **Amazon アソシエイト**へ直接申請。Basic 認証を外してから申請すること（審査員がサイトを閲覧できる必要がある）
3. `AffiliateButtons` コンポーネントに Amazon タグ・もしもの各 ID を設定。ID は `src/data/siteData.ts` に集約し、ASP を切り替えるときは定数 1 箇所の変更で済むようにする
4. 記事冒頭に「本記事にはアフィリエイト広告が含まれます」の表記（ステマ規制対応）
5. プライバシーポリシーページに Amazon アソシエイト・もしもの規定文言を記載
6. 180 日以内に 3 件の Amazon 売上が必要なので、公開初期は自分の SNS でも記事を流して初動を作る

## 7. サイト側の実装タスク（次のステップ）

1. `profile` / `privacy-policy` / `contact` ページの新設
2. frontmatter スキーマ拡張（5-2）と、既存 7 記事への値の追加
3. コンポーネント新設（5-3）: `Verdict` `SpecTable` `AffiliateButtons` `Rating` `TastingNote` `Recipe` `ProsCons` `RelatedBottles` `FAQ` `CompareTable`
4. `compare` / `guide` コレクションとページの新設
5. タグページ `/tag/[tag]` の新設と用途タグの追加
6. 記事ページに JSON-LD（`Product` + `Review` + `FAQPage`）を出力
7. トップページを「新着 → 価格帯別まとめ → 飲み方別まとめ」の構成に変更
8. 既存 7 記事を新テンプレートで書き直し + 比較・ブランド・まとめ記事を 3 本追加して計 10 記事にする
