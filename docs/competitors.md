## 使い方

- **記事を書くとき**: A から 3〜5 件 + D を読んで、香りの系統・いちばん合う飲み方・弱点の平均を取る。1 サイトをなぞらない。
- **タイトルを決めるとき**: ぴろ / ウイスキーを知る / 酒おやじ のタイトルの型を参考にする。
- **狙う語を決めるとき**: B が持っている語（おすすめ、ランキング、安い）は避け、「{銘柄} まずい」「{A} {B} 違い」「{ブランド} 全種類」から入る。
- **表示・機能の参考**: いのかず（評価の見せ方）、酒おやじ（3 ボタンと FAQ）、WhiskyData（スペック表の項目）。
