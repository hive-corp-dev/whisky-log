# レビュー記事の構成・セクション別執筆マニュアル

更新：2026-09-11。アラン10年・陸・ブラックニッカ スペシャルの改稿で確認した指示を、記事の上から順に整理した執筆用の構成表。次の記事はこの順番で確認・修正する。本人の新しい指示を最優先する。

基本構成は「導入 → 結論 → 基本情報 → 銘柄の説明 → 香り・味・余韻 → 飲み方別の評価 → ネットでの評判 → 評価まとめ」。評価まとめの中は「点数表 → 感想 → おすすめする人・しない人 → 締め」の順。既存の画像・商品カードの位置は維持し、本文とカードを一続きで読む。

## タイトル

- おすすめの飲み方を毎回タイトルに入れる必要はない。銘柄のコンセプトや特徴が伝わる言葉を選ぶ。オーチャードハウスでは「果樹園」のイメージを優先する（2026-09-11指示）。
- 既存記事の評価や売れ行きに引っ張られず、調査と本人の指示から考え直す。過去の品薄を現在の入手難として引き継がない。

## 1. 導入文

### 何を書くか

どんな銘柄を紹介するのかを簡単に伝え、本人とそのボトルとの関わりを書く。

### 書く順番

1. 銘柄の簡単な紹介。
2. 買った場所やきっかけ、本人の好み・思い入れ。
3. 今回紹介する香り・味わい・飲み方のレビューへの案内。

### 細かいルール

- 本人のメモや追記を材料にする。アラン10年なら「近所の酒屋でデザインに惹かれて購入」「お気に入りのトップ5」。
- 購入場所や体験を創作しない。材料が足りなければ本人に聞くか、確認できている内容だけで書く。
- 購入の経緯は必須ではない。特に書く必要がない銘柄では、簡単な紹介や本人の評価だけで導入を組み立ててよい。
- 度数・ノンチルフィルタード・無着色などの仕様の羅列はしない。詳しい説明は「とは」で書く。
- 「オレンジ色のラベルが目印です」のように、紹介する意味が薄い一文で埋めない。
- 吹き出しを使う場合は本人の短いコメントにする。本文と同じ感想をもう一度言わせない。
- すべての銘柄を同じ導入にしない。

## 2. 冒頭の結論

### 何を書くか

この記事を読む前に知っておきたい魅力と、どんなボトルを探している人に合うかを短い箇条書きで示す。データ上は `verdict`。

### 項目の組み立て方

味の主な魅力、特に良かった飲み方、選ぶ理由・おすすめの対象から、その銘柄で大事な内容を選ぶ。

### 細かいルール

- 基本的にはポジティブにまとめる。ただし重大な欠点は隠さない。
- ストレート・ロック・ハイボールを1項目ずつ書く必要はない。
- 数は3つに固定しない。2つでも4つでもよい。現行スキーマの上限は4つなので、それ以上必要なら実装を確認する。
- アラン10年ではロックの項目を外し、フルーティで少し良いハイボール用のボトルを探す人への勧めを入れた。
- 後の本文や点数と矛盾させない。項目を埋めるために弱い説明を足さない。

## 3. 基本情報

### 何を書くか

銘柄名、メーカー、蒸留所、熟成樽、度数、容量、価格など、購入・比較に必要な事実を既存の表に入れる。

### 細かいルール

- 既存の表の構成を基本的に維持する。
- 仕様は公式情報やボトル表示で確認する。資料が食い違う場合はボトルや時期の違いを調べる。
- 価格は税込で、確認時期を記録する。出品例や古い口コミだけで現在の相場を断定しない。
- この表で分かる数値を、他のセクションでも理由なく繰り返さない。

## 4. 「○○とは」

### 何を書くか

どのようなウイスキーなのかを説明する。ブランド内の位置づけ、熟成年数、熟成樽、製法など、その銘柄の特徴を中心に書く。

### 書く順番

1. 産地・銘柄の位置づけなどの簡単な説明。
2. 熟成や造りの特徴。
3. 関連する豆知識があれば短く紹介。
4. `KeyPoints` で特徴を整理。

### 細かいルール

- 度数、ノンチルフィルタード、無着色の説明はここで扱ってよい。
- 蒸留所の歴史を長く説明すること自体を目的にしない。
- ポイント欄は樽や造りなどの特徴を優先し、蒸留所名だけで1項目を埋めない。
- 豆知識は裏付けがあり、面白いものがあれば入れる。必須ではない。
- 終売などの話題にH3を設ける場合、その説明はH3内にまとめる。直前の本文で先に説明して重複させない。H3見出しは句点で二つに分けず、一文で書く（バランタイン12年の修正指示）。
- 「造り手の考えが込められています」のような抽象的な意味づけだけで豆知識を膨らませない。具体的に何が分かるのかを説明し、直前の説明と重なるだけなら足さない。ブラックニッカ スペシャルのラベルに関する補足段落は、この理由で削除した。
- 終売・後継品・リニューアルに触れる場合は公式情報で確認する。
- グレーン主体などの原酒構成も、そのボトルの特徴として本文とポイント欄に入れられる。原材料の記載順だけで配合比率を断定せず、公式の説明で裏付ける。陸では公式に確認できた「グレーン原酒主体」を採用した。
- メーカーからの説明を紹介する文は「〜になったとのこと。」「〜しているようですね。」などの伝聞表現も使う。自分の実飲感想と区別しつつ語尾を整えるための選択肢で、未確認情報をごまかす用途には使わない。発売日や度数まで一律に曖昧にしない。
- 説明のたびに「公式サイトでも紹介されています」と付け足さない。リンクが必要な箇所は本文の自然な語句に付ける。陸では原酒構成の公式説明リンクは残し、リニューアルの出典リンクと製法説明後の製品情報への案内は削除した。すべての公式リンクを削除するルールではない。
- 吹き出しを使うなら説明への本人のひとこと。仕様をただ繰り返さない。

## 5. 香り・味・余韻

### 何を書くか

香り・味わい・余韻の各項目で特徴を簡潔に伝える。導入では結果を先に説明せず、テイスティングへの案内だけを書く。

### 書く順番と内容

1. **セクションの導入**：「それでは、実際に飲みながら香り・味わい・余韻をチェックしていきます」のように、これから確認することを短く案内する。
2. **香り**：最初に感じる香り、甘さ・果実・香ばしさなどの組み合わせ。
3. **味わい**：口当たり、甘み・酸味・苦みのバランスや変化。
4. **余韻**：飲んだ後に残る風味、長さ、飲み終わりの印象。

### 細かいルール

- 導入に香味の結論を先取りして書かない。「バニラの甘い香りに、果実や穀物の風味が感じられます」などは各項目に任せる（陸の修正指示、2026-09-11）。
- 各項目はカフェグレーンの記事を目安に、最低2段落で書く。必要なら増やしてよい。既存文に付け足すだけで済ませず、香味の関係や前後のつながりから組み直す（2026-09-14指示）。後のストレート欄とは、香味の説明と飲んだ評価で役割を分ける。
- 単語の羅列だけではなく、香味の関係が分かる文章にする。
- Whisky Labの複数ソースの共通傾向と本人のメモを確認する。珍しい一例を主な特徴として扱わない。
- 元サイトの文をなぞらず、未確認の細かな変化も補わない。
- 香り・味わい・余韻の各項目に必ず1か所以上の強調を入れる。特徴の核を選び、すべての文や段落全体を強調しない（2026-09-14指示）。

## 6. 飲み方別の評価

### 何を書くか

ストレート・ロック・ハイボールで、何が変わり、どこがおいしく、どこが気になるかを書く。各 `TastingNote` に写真と本人の点数を対応させる。

### 6-1. セクションの導入

「ストレート・ロック・ハイボールの3つの飲み方で試してみます」のような短い一文でよい。ここで3種類の評価を先に説明しない。

### 6-2. ストレート

**何を書くか：** そのまま飲んだときの口当たり、飲みごたえ、香味の感じ方、アルコールの刺激など。

**ルール：** 前の香り・味・余韻を丸ごと繰り返さず、飲んだ評価を中心にする。アルコール感が気になるなら正直に書き、無理に長所へ言い換えない。

### 6-3. ロック

**何を書くか：** 冷やしたときの香りや口当たり、氷が溶けるにつれて感じる変化、甘さや苦みの印象。

**ルール：** ストレートとの差が伝わるようにする。後半の苦みなどの気になる点も残す。冷却・加水の変化を裏付けなく補わない。

### 6-4. ハイボール

**何を書くか：** 炭酸で割ったときの香り、甘みの残り方、爽やかさ、飲みごたえ。濃さや食事との相性は根拠があれば添える。

**ルール：** 「アラン10年は」のように銘柄紹介から再開せず、「炭酸で割ると」など変化から入る。ストレートがおいしいからハイボールにはもったいない、と決めつけない。

### 飲み方別に共通するルール

- 飲み方別の本文は筆者自身の評価として書く。「〜というレビューがある」「〜という評もある」「〜と感じる人もいる」と他人の評価を紹介する文章にしない。他サイトの紹介や意見の違いは「ネットでの評判」に分ける。参考調査は執筆の材料であり、この欄を調査報告にしない。
- 本人の感想と他サイトの評価を混同しない。他人の体験を本人の実体験として書かない。
- 複数レビューの「平均」は、文言や点数の単純平均ではなく共通傾向の整理。
- 本人の点数が未入力なら、他サイトの点数で勝手に確定しない。
- 本人から点数の調整と判断を任された場合は、複数の実飲レビューと本文の評価を照らして調整し、理由を伝える。依頼されていない総合点などまで連動して変更しない。おすすめの飲み方は本人の判断を優先し、冒頭の結論と `recommendedWay` を一致させる。
- 良い点も気になる点も率直に書く。各飲み方を無理に同じ長さにそろえない。
- 低価格帯の記事でもストレートやロックの欠点を隠さない。ただし「安いから刺激が強い・単調」と推測せず、実際のレビューで確認した内容を書く（陸の初稿指示、2026-09-11）。
- すでに星が表示されているので「満点の5にしました」と本文で再説明・強調しない。
- 吹き出しは本文にない本人の短い感想が自然に入るときだけ使う。

## 7. ネットでの評判

### 何を書くか

本人以外の評価も購入判断に使えるよう、確認できたレビューの良い声と気になる声を紹介する。設ける場合は、飲み方別の評価の後・評価まとめの前に置く。

### 書く順番

1. どのようなレビューをまとめたか、短い導入。
2. `ProsCons` の「良い声」「気になる声」。
3. 確認したレビューで評価されている傾向。
4. 気になる声についても、本人の考えを添える。良い評判への感想だけで終わらず、共感する点や自分とは違う点を、共有済みの本人の評価に沿って書く。本人の判断が不明な点は勝手に同意・反論しない。

### 細かいルール

- 良い声と気になる声の数をそろえるために、未確認の意見を足さない。
- 「購入者レビュー」と「実飲ブログ」など、実際の確認元に合う導入にする。
- 相場や商品の特徴に関係のない特殊な出品条件を、一般的な欠点にしない。アラン10年の「1万円前後まで高騰」は不採用。
- 旧ボトル、配送トラブル、購入時の価格などの条件を落とさない。
- 「多い」と書くなら確認範囲を明示する。抜粋だけからネット全体の多数意見や順位に広げない。
- 本人の考えは推測と分かる書き方にする。アラン10年では、46％なので飲み慣れていない人には刺激が強く感じられることもあるのでは、という感想を添えた。
- 「甘い」「ハイボールで飲みやすい」を「クセが少ない」「誰でも飲みやすい」と同一視しない。陸では本人が香りのクセを感じているため、「クセが少なく、飲みやすい」の項目は削除した。他人の声と本人の感想が異なる場合も、両者を区別して説明する。
- カード後は、良い評判で評価されている理由に触れてから、気になる声への自分の考えへつなぐ。陸では「ハイボールのおいしさと手頃な価格が高評価」→「香りのクセや刺激はあり、誰にでも飲みやすいとは言いにくい」の順で了承。カードの箇条書きを読み上げ直すのではなく、筆者の判断を加える。
- 出典と確認範囲は編集メモに記録する。名前を省く・少し言い換えるだけで権利や利用条件の問題が解消したとは扱わない。

## 8. 「○○の評価まとめ」

ここは一続きのセクション。以下の4つを順に書き、カードを挟んでも話が重複しないようにする。

### 8-1. 点数表

**何を書くか：** `Rating` で本人の各評価とおすすめの飲み方を示す。

**細かいルール：** 飲み方別の点数と一致させる。表にある点数を直後の文章で繰り返さない。

### 8-2. 全体の感想と、特に好きな飲み方

**何を書くか：** 飲んでどう思ったか、そのボトルのどこを気に入ったか、特に良かった飲み方と理由を書く。

**細かいルール：**

- 「○○は、蜂蜜とリンゴと柑橘を楽しめるシングルモルト」のような製品の定義からやり直さない。
- 本人の追記を芯にして整える。長さより、感想として自然に読めるかを優先する。
- 話題ごとに段落を分ける。必要な内容は残し、同じ感想を言い換えて水増ししない。
- 気になる点を触れる必要があれば正直に書く。すべての飲み方を再レビューする必要はない。
- この後の締めで「家に1本置く理由」を書くなら、ここで同じ説明を済ませない。

### 8-3. おすすめする人・しない人のカード

**何を書くか：** 味の好みや普段の飲み方に合う人、合いにくい人を `ProsCons` で具体的に整理する。

**細かいルール：**

- 本文と逆のことを書かない。ハイボールを高評価にしているのに、ハイボール用の人には合わないとしない。
- 項目を埋めるために、どの銘柄にも使える対象を足さない。
- すべての銘柄をシングルモルト入門向けにしない。アラン10年では入門向けの項目は最終的に削除指定。
- カード前後の文章も含めて読む。「おすすめです」→カード→「おすすめです」の反復を避ける。

### 8-4. 選ぶ理由と最後のひと押し

**何を書くか：** 家に置いておく意味や、どんな1本を探す人に選んでほしいかを伝えて、購入・試飲を後押しする。

**書く順番：** 本文を受けた選ぶ理由 → 対象を示して「ぜひ買ってみてください」「ぜひ試してみてください」。

**細かいルール：**

- ここで香味や飲み方の解説を再開しない。唐突に初心者向けの話を足さない。
- 導入の購入エピソードに戻れば自然になるわけではない。アラン10年ではその案は不評だった。
- 「予算は上がりますが」など、必要のない一般論で勧める力を弱めない。
- カード前ですでに勧めている場合、まず「重宝すると思います」など選ぶ理由としてつなぐ。同じ「おすすめです」を重ねない。
- 重複を指摘されても、万能さなど本人が残したい内容を消さない。位置を移す、役割を分ける、前後をつなぎ直す。
- 強調するのは選ぶ理由の部分。購入を促す一文全体を太字にしない。
- 短くすることを目的にせず、本人が指定した表現を尊重する。

アラン10年で了承された例：

> その日の気分で飲み方を変えられる万能さがあるので、家に1本置いておくと重宝すると思います。
>
> **フルーティでハイボールにも合う、いつもより少し良いウイスキー**を探している人は、アラン10年をぜひ買ってみてください。

この文章を他銘柄へそのまま流用せず、対象のボトルに合う理由に変える。

## 全セクションに共通する表記・部品のルール

- 丁寧語を基本に語尾をばらけさせる。ただし「ですね」や体言止めの機械的な挿入はしない。「後味は爽快」のような表現も前後が自然なら使える。
- 銘柄が明らかな文脈で名前を何度も書かない。
- 各所で要点を `**強調**` するが、段落全体や点数などの重複情報を強調しない。
- MDXでアスタリスクがそのまま表示される箇所は、明示的な `<strong>...</strong>` に置き換えて生成HTMLを確認する。文章の長さが原因と決めつけたり、強調を外すだけで済ませたりしない。
- 吹き出しは既存の `Speech` を使用し、標準は枠線（`style="border"`）。本文と同じ書き手なので「私もそう思います」と別人のように同意しない。
- 吹き出しの回数は固定しない。節末などで短いコメントを添えるが、本文の繰り返しなら配置や内容を見直す。アラン10年の完成稿は本人指定で0か所。
- 本人の追記は、内容とニュアンスを保って整える。未共有の体験・点数・好みは作らない。
- 英単語と日本語の間に不要なスペースを入れない。
- 元のURL・画像・アフィリエイト部品を不用意に変えない。商品画像の欠落も確認する。
- 本文の外部リンクは `ExternalLink` を使える。通常のMarkdownリンクでも外部URLは自動判定し、末尾アイコンと新規タブ表示を付ける。色はメインカラーのオレンジ、下線あり。リンクのスタイルは専用CSS Moduleにまとめ、目次・購入ボタンと混在させない。

## 次の記事での確認手順

1. このマニュアルを上から読み、対象記事とWhisky Labの本人メモ・参照情報を確認する。
2. 本人の追記と確定済みの評価を把握してから、各セクションを整える。
3. 文章の参考が必要なら実際のブログを開き、単語だけでなく構成とカード前後の文章を確認する。文章はなぞらない。
4. 完成後に記事を上から通読する。カードを挟んだ重複、説明の再開、語尾・主語・強調の偏りを見る。
5. MDXを変更した場合は `npm run build` で確認する。文章資料だけの変更ならビルドは不要。
6. 新しい指示は該当セクションのルールへ追記する。今回依頼された記事以外を一括で変更しない。

補足として、過去の具体例やアラン10年に固有の本人の好みは [編集上の補足メモ](./writing-preferences.md) に記録している。執筆時の主資料はこのマニュアルとする。
