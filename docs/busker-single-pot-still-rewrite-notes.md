## 調査と編集方針

- Whisky Lab `data/busker-single-pot-still.json` の10ソースの香り・味わい・余韻・飲み方を照合。本人のmineは全項目未入力。後続のユーザー指示で概算評価を委任されたため、数値と文章の評価傾向からストレート3.5、ロック4、ハイボール3.5、コスパ4、総合4を設定。おすすめはロック。厳密な算術平均ではない。
- 甘さ、クリーミーさ、スパイス、樽のビターを共通傾向として整理。なもなきアクアリウムの梅酒表現は本人の今回の感想とも一致するが、独特の文言は転用しない。
- ロックの甘苦さはひろりんパパ、榎商店、ラウンドアップ、sister-ley等を参照。刺激の増減には差があるため、冷却で全ての刺激が消えるなどの断定はしない。
- 「世界の蒸留酒を制覇したい！」のhighball欄はトニックウォーター割りのため、通常のソーダ割りの根拠には使わない。
- 旧ボトルの海外レビューは補助資料とし、現行仕様や相場の根拠にしない。古い価格・品薄情報は引き継がない。価格は今回確認できた購入価格がないので基本情報に未設定。
- 他サイトの点数を本人の点数として転用せず、飲み方は通常のH3で仮組み。香り・味わい・余韻は各2段落、各項目strongあり。
