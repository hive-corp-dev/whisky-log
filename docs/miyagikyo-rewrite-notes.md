# 宮城峡の記事・改稿メモ

2026-09-11。追加修正後、価格説明の段落を削除して完成と本人確認済み。以下は改稿履歴であり、最新の本文とセクション別執筆マニュアルを優先する。

## 初稿後の修正

- 最終指示で本文のメーカー参考小売価格の説明段落とリンクを削除。基本情報の価格7,700円は維持。出典は本メモに残す。
- 本人指定でタイトルから硫黄感を外し、「りんごのような香りとなめらかな甘さ」に変更。本文の硫黄感は残す。
- 飲み方別は本人の評価として読める視点で書くよう指定。「レビューがある」「という評もある」などの調査紹介を外し、感想として整えた。新しい実飲メモや点数の確定があったわけではないため、香味の具体的な強さ・好みは引き続き本人確認対象。
- ハイボール欄にはスモークや煙たさを書かない。その他のセクションのスモークを一律に削除する指定ではない。

## 依頼と判断

- 導入は維持。旧稿の「ロックがいちばん」に引っ張られず、タイトル、結論、香味、飲み方別、まとめを再検討。ネット評判を追加。
- いったん調査を停止し、本人がLabを追加した後、`../whisky-lab/data/miyagikyo.json` 全体を読み直して再開した。初回のLab未登録時の仮案より追加データを優先。
- Labの本人欄はすべて未入力。新しい購入体験や「自分は硫黄が気にならなかった」などの個人的事実は創作しない。記事の評価とコメントは確認用の編集案。
- おすすめはロックとしたが、全サイトで最上位という意味ではない。なめらかな甘さを評価する複数記事を判断材料とし、硫黄感や渋みが残るという反対意見も本文に反映。
- 星は確認用の仮案としてストレート3.5、ロック4、ハイボール4。総合3.5・コスパ3は既存値を維持。異なる尺度の点数や未採点レビューを単純平均していない。本人の確定点ではない。
- ハイボールは否定的な一記事だけを一般化しない。複数の好意的な評と酸味・えぐみへの指摘を両方扱った。
- 硫黄・ゴムの匂いを省かず、強く感じる人と気にならない人がいると説明。シェリー樽が原因とするブログはあるが、当該ボトルの匂いの原因を公式に確認したわけではないので因果は断定しない。
- 余韻の長さ、ボディの厚さ、加水後の変化はレビュー間で一致しないため、旧稿の断定を引き継がない。
- 元URL・画像・商品カードの仕組みを維持。強調はstrongタグ、吹き出しは枠線で1か所。

- [ひろりんパパ](https://whiskyjp.com/シングルモルト-宮城峡/)：2023年の単体レビュー。甘さと硫黄・ゴムの風味、ロックとハイボールの評価。

- [ぴろ](https://www.piroriro.com/entry/miyagikyo-review)：果実や花、強い硫黄・ゴムの風味、苦みとスモーク。飲み方別評価はないため、その比較には使わない。

Labのウイスキートマトは補助的に参照。「ウイスキーを知る」は解説型で独立した実飲票として数えない。記事なしの2サイトは対象外。追加調査で[榎商店の実飲記事](https://enokishouten.co.jp/blog/miyagikyou-review)も確認し、ロックの甘さ、残る硫黄感、ハイボールの果実感を補助的に参照した。

ひろりんパパの2026年記事に関するLab内補足は、旧ラベルとの比較・筆者の見解として区別。原酒構成変更や硫黄感の消失を全ボトルに適用しない。古いレビューの価格を現行の相場として転載しない。
