# 白州（ノンエイジ）の記事・編集メモ

2026-10-17 初稿。記事: `src/content/review/hakushu.mdx`（URL `/review/japanese/hakushu/`）。サムネは本人がチャットに貼った写真（`images/12.jpg`、2000px に縮小。「SINCE 1973」の現行ラベル）。公開日は連番で 10/18。

## 判断

- 本人指示は「つぎはくしゅう」のみ。Lab の本人欄は未入力なので、感想は確認したレビュー（31 サイト）の共通傾向から組み立てた編集案。新旧ラベルの違い（スニフ）は本文に入れていない。
- 星: ストレート 4 / ロック 4 / ハイボール 5 / コスパ 2.5（総合 3.9）。
  - ストレート: ひろりんパパ 4.5、晩酌 4、たる「なめらか」。ジーク・エンカウント・くりりん・WhiskyNotes は若さ・刺激を指摘。4。
  - ロック: ひろりんパパ 4.5、晩酌 4、ゆう・なもなき・トマト 好評。sister-ley・燃える美食は苦みを指摘。4。
  - ハイボール: ひろりんパパ 5、晩酌 5、ゆう・なもなき・トマト・sister-ley・WHISKYSTART・めがね 一番。5。
  - コスパ: 希望小売 7,500 円税別（2026-04 改定、旧 7,000 円税別＝7,700 円税込）、楽天 11,800〜12,850 円。「プレ値で買う価値はない」（晩酌、ひろりんパパ、めがね、燃える美食）が多数。2.5。
- 参考価格は定価の 8,250 円（税込）。実売が 1 万円超なので、本文で定価と実売を分けて書いた。楽天は `searchKeyword` 検索（実売 12,000 円台の商品が出る）。
- 仕様: 白州蒸溜所 1973 年開設（サントリーウイスキー誕生 50 周年）、山梨県北杜市、標高 700m、南アルプスの天然水。NA は 2012 年発売（12 年の代替、ゆう・なもなき・たる）。43%・700ml。180ml ミニボトルがコンビニで定価（ひろりんパパ、なもなき、榎）。
- 希望小売価格は 2026-04 改定の報道（グルメ Watch 要約「山崎 NV・白州 NV は 7,000 円→7,500 円税別」）を採用。
- 香味は共通要素のみ: 若葉・ミント・森（森林浴）、青りんご、洋梨、蜂蜜・バニラ、すだち・ライム・柑橘、ほのかなスモーク、軽いボディ、緑茶のような苦み、若さ、短めの余韻。「ヒノキ」「硫黄っぽさ」「きゅうり」「麹」は一例なので不採用。
- 関連リンクは無し（山崎・知多との関連付けは今回なし）。
