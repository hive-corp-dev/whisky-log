# ネクタロシティ改稿メモ

2026-09-11。本人確認用の文章案。

- 本人の今回の感想：ロックは他人の否定的なレビューほど悪く感じず、甘みが大きく増した。この感想をロック欄の軸とし、ネット評判の後では他人との違いとして記載。
- 飲み方欄は他サイトの紹介にせず、ラボにある共通傾向を元にした文章案。未確認の購入場所・購入経緯は作らない。
- 初稿では星を据え置いたが、本人の追加指示でロック3.5→4、ハイボール4.5→4に変更。現在はストレート4／ロック4／ハイボール4／コスパ3／総合4。おすすめハイボールは維持。
- タイトルは蜂蜜と焼き菓子の甘さを中心に変更。商品紹介は菓子作りのコンセプト、原酒構成、特注樽の使い方を整理。
- 旧稿の「グレーンが入っているから軽い」「46度でも刺激は弱い」「ロックは溶けるほど単調」「高価なハイボールは気が引ける」は引き継がない。
- ネット評判を追加。国内3件・海外3件の実飲を参考とし、公式ノートは評判の件数に含めない。否定的な意見と本人の感想を混同しない。
- 元URL、画像、アフィリエイト設定を維持。ラボのmineは変更しない。
