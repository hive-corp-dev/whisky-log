## 参照元

### 「気になる声」の再調査（2026-09-11）

本人の依頼で新たに検索し、以下の原ページのレビュー本文を確認。すべて緑のブレンデッド（Triple Cask Triple Smooth）についての意見。逐語引用ではなく短い要約として掲載し、ネット全体の多数意見とは扱わない。

- [のぶたん / WhiskyNotes #23](https://note.com/nobtan50/n/naa5b2990e9a8)（2026-03-28）：2日目のソーダ割りで香りに人工的な印象を受けたという感想。初日はおいしいと評価し、後日レモン入りでは好印象に変わっている。本文の項目はハイボールに限定。香料添加などの製品事実を意味しない。
- [Whisky Connosr / Megawatt](https://www.connosr.com/the-busker-triple-cask-triple-smooth-whisky-review-14670)（2023-03-18）：香味が単純で、苦みが味のバランスを崩しているという評価。特定の飲み方の指定はないため、ロック限定などの条件を補わない。
- [Master of Malt / Simian P](https://www.masterofmalt.com/whiskies/the-busker/the-busker-triple-cask-triple-smooth-whiskey/)（2023-03-06、購入者レビュー「Ok for the price」）：クリーミーな口当たりを認めつつ、味に物足りなさを感じたとの評価。前のCon nosrの単純さの指摘と併せて「味わいが単調で、物足りない」と要約。英国の当時価格を日本の現在価格へ転用しない。

カード下は既存の筆者の評価（華やかなハイボールを好む、ロックでは苦み、普段飲みとして満足）に沿って接続。人工的な香りを本人も感じたとは書かず、点数・飲み方別本文は変更しない。

Labのゆうの家飲み、ひろりんパパ、なもなきアクアリウム、晩酌ノオトの実飲情報を中心に参照。いのかずのまとめ記事は補助。「ウイスキーを知る」は解説型で、度数44％という記載は採用しない。記事なしのサイトは比較対象外。

原ページも確認した資料：

- [ゆうの家飲み](https://you-whisky.com/2022/07/24/busker-blended/)：甘さとスパイス、ロックの苦み、ハイボールの果実感とすっきりした後味。
- [晩酌ノオト](https://bannote.com/busker-green-review/)：トロピカルな香り、なめらかさ、ハイボールと食事の相性。固有の購入体験・家族との会話は採用しない。
- [正規輸入代理店の発売発表](https://prtimes.jp/main/html/rd/p/000000009.000077585.html)：国内商品名、2020年ブランド誕生、2016年蒸留所操業開始、3原酒、3樽、フローリオのマルサラ樽、40％・700ml。

ハイボールの好評と価格への満足感は複数の参照記事で共通。ロックには肯定的な評もあるため、苦みや香りの控えめさを欠点として挙げつつ、まろやかな甘さも残した。
