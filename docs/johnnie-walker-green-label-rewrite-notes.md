# グリーンラベル15年 改稿メモ

2026-09-11。本人確認用の文章案。

## 本人の指示・変更

- 追加の点数指定により、ハイボールを4→4.5に変更。その他の点数とおすすめの飲み方は変更なし。

- 追加修正：まとめの「その日の気分で楽しみたい」という吹き出しを削除。締めの「飲みごたえのあるモルト」は曖昧との指摘を受け、果実の甘さ・スモーキーさと、ハイボールの草木の香りを選ぶ理由に書き直した。

- 本人の感想「ハイボールで衝撃を受け、草原や森林のイメージが浮かんだ」をハイボール欄に反映。本人の比喩として記載し、全員が同じ景色を感じるという説明にしない。
- ラボの香味・飲み方の共通傾向から全体を再構成。ハイボールを低く見る一部のレビューより、本人の体験を優先。
- 旧稿の「必ず3段階で味が変わる」「4蒸留所の味が個別に分かる」「ストレート以外はもったいない」「ハイボールならブラックで十分」「小さい氷が良い」は削除。
- 星はストレート4.5／ロック4／ハイボール4／コスパ4.5／総合4.5の既存値を維持。おすすめストレートも維持しつつ、本人のハイボールへの好意を本文・結論に反映。ハイボールへの感動だけで点数や順位は勝手に確定しない。
- タイトルは草木の香りとモルトの甘さを中心にした。ネット評判を追加。本文は本人確認用の案であり、追加の購入体験は作らない。
- URL、画像、アフィリエイト設定、ラボのmineは変更しない。
- 樽の表記は、今回確認できたアメリカンオーク／ヨーロピアンオークに変更。以前入っていたバーボン／シェリーの内訳は断定しない。
